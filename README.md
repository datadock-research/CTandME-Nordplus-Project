CTandME Nordplus Project
-----
Co-designing Computational Thinking and Mathematics Curriculum Framework for Nordic-Baltic Preservice Teacher Education
This repository provides documents, project materials, and outputs developed within the Nordplus Higher Education project“Co-designing Computational Thinking and Mathematics Curriculum Framework for Nordic-Baltic Preservice Teacher Education.”

**Project information**
Project acronym: CTandME

Project ID: NPHE-2025/10158

Programme: Nordplus Higher Education

Project period: 2025–2028

Coordinating institution: Norwegian University of Science and Technology, NTNU

Project coordinator: Melih Turgut

Project (Year 1) Website: https://www.ntnu.edu/ilu/research/computational-thinking-mathematics-curriculum-framework
-----
**Partner institutions**
Norwegian University of Science and Technology, Norway
Uppsala University, Sweden
Tallinn University, Estonia
Vilnius University, Lithuania
-----
**Project aim**
The project aims to collaboratively design, pilot, and refine a research-based Computational Thinking and Mathematics curriculum framework for preservice teacher education in the Nordic-Baltic region.
